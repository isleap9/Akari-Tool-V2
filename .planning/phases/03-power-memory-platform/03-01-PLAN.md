## Abstraction: IPowerManager

public interface IPowerManager

**FakePowerManager** — in-memory dictionary tracking scheme states (logic-only, per D-04)

**PowerManager** — Production implementation using `Process.Start("powercfg.exe", ...)`

## Executor: PowerOperationExecutor

Implements `ITweakExecutor` for `TweakType.Power`:
- `CanHandle(TweakType.Power)` → true
- `ApplyAsync`:
  1. If PWR-01 (Ultimate Performance): Check if scheme exists → duplicate + activate
  2. If fails or scheme not found: Fall back to PWR-02 (High Performance) (Pitfall 9)
  3. Log all operations to ILogService
- `RevertAsync`:
  - Restore default schemes: `powercfg -restoredefaultschemes`
  - Enable hibernate
  - Log all operations
