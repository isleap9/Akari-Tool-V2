|----------|-------------|
| Test ↔ Production registry | FakeRegistryProvider (in-memory, no ACL) vs Win32RegistryProvider (real HKLM writes, ACL enforced) |
| Elevated vs non-elevated | Registry writes to HKLM require admin — non-elevated runs are blocked by manifest (Phase 4) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | Registry key paths from tweak catalog | medium | mitigate | Validate keyPath format against known hive prefixes (HKLM, HKCU, etc.) before passing to OpenBaseKey |
| T-01-02 | Tampering | Registry values from tweak catalog | medium | mitigate | Type-check values against RegistryValueKind before SetValue; reject unsupported types |
| T-01-SC | Tampering | `Microsoft.Win32.Registry` NuGet install | high | mitigate | Package is part of .NET 10 runtime (no NuGet install needed — verified via dotnet --version = 10.0.400) |
| T-01-03 | Repudiation | Registry write failures | high | mitigate | All operations logged via ILogService to %LOCALAPPDATA%\Akari\App\logs\ with timestamp, operation, key path, and exception detail |
</threat_model>
