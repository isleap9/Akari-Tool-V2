<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Tweak catalog vs RegistryWriter | Tweak definitions are JSON data — validated against known paths before execution |
| HKCU vs HKLM | Most tweaks are HKLM (requires admin); Mouse Acceleration is HKCU (no admin needed) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering | Registry value data (enabled/disabled values) | medium | mitigate | Each tweak provides typed values — DWORD or String — with explicit types; executor validates type matches registry value type |
| T-03-02 | Tampering | Registry key path from JSON catalog | medium | mitigate | Registry paths are hardcoded in tweak classes (not user-controllable); catalog is a trusted static file |
| T-03-SC | Tampering | `Microsoft.Win32.Registry` API usage | high | mitigate | Uses IRegistryProvider abstraction (no direct RegistryKey calls in tweak classes); package is built into .NET 10 runtime |

</threat_model>
