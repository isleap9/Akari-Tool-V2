## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| State file vs Registry | State service reads actual registry values for re-validation; mismatched values indicate Windows Update revert |
| Log file vs Engine | All operations logged; log is ground-truth for runtime ACL failures (per D-04) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering | State file content | medium | mitigate | Validate JSON structure on load; reject corrupt state file and start fresh |
| T-02-02 | Repudiation | Tweak application without logging | high | mitigate | ILogService logs every Apply/Revert with timestamp, tweakId, and outcome |
| T-02-SC | Information Disclosure | Log file at %LOCALAPPDATA% | low | accept | Log directory is user-specific; admin-only access already enforced by Windows |

</threat_model>
