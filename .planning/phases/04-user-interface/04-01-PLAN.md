## Architecture

### Dependency Injection (App.xaml.cs)
```csharp
public partial class App : Application
{
    public IServiceProvider Services { get; private set; }

    protected override void OnLaunched(LaunchActivatedEventArgs args)
    {
        var services = new ServiceCollection();
        ConfigureServices(services);
        Services = services.BuildServiceProvider();

        var mainWindow = Services.GetRequiredService<MainWindow>();
        mainWindow.Activate();
    }

    private static void ConfigureServices(ServiceCollection services)
    {
        // Engine services
        services.AddSingleton<ILogService, FileLogService>();
        services.AddSingleton<IRegistryProvider, Win32RegistryProvider>();
        services.AddSingleton<ITweakStateService, JsonFileStateService>(sp =>
            new JsonFileStateService(
                sp.GetRequiredService<IRegistryProvider>(),
                Path.Combine(Environment.GetFolderPath(Environment.SpecialFolder.LocalApplicationData),
                    "Akari", "App", "state.json")));
        
        // Executors
        services.AddSingleton<ITweakExecutor, RegistryTweakExecutor>();
        services.AddSingleton<ITweakExecutor, ServiceOperationExecutor>();
        services.AddSingleton<ITweakExecutor, ProcessOperationExecutor>();
        services.AddSingleton<ITweakExecutor, PowerOperationExecutor>();
        services.AddSingleton<ITweakExecutor, MemoryOperationExecutor>();
        
        // Catalog — load from embedded/app-level tweaks.json
        services.AddSingleton<ITweakCatalog>(sp =>
        {
            var catalogPath = Path.Combine(AppContext.BaseDirectory, "tweaks.json");
            return JsonTweakCatalog.FromFileAsync(catalogPath).Result;
        });
        
        services.AddSingleton<ITweakEngine, TweakEngine>();
        
        // ViewModels
        services.AddSingleton<MainViewModel>();
        services.AddTransient<MainWindow>();
    }
}
```

### MainWindow (NavigationView + Checklist)
- `NavigationView` with `Pane` = ListView of categories, `Content` = ItemsControl of tweak checkmarks
- Categories populated from `ITweakCatalog.GetAllAsync()` → grouped by `Category` field
- Each tweak rendered as a CheckBox (IsSelected) + Apply/Revert Button + status text (IsApplied)

### ViewModel Hierarchy
```
MainViewModel (singleton)
├── ObservableCollection<TweakCategoryViewModel> Categories
├── TweakCategoryViewModel SelectedCategory
├── ObservableCollection<TweakViewModel> SelectedTweaks
├── ICommand ApplySelectedCommand
└── double BatchProgress (0-100)

TweakCategoryViewModel
├── string DisplayName (e.g. "Registry", "Power")
└── ObservableCollection<TweakViewModel> Tweaks

TweakViewModel
├── string Id (e.g. "REG-01")
├── string Name (e.g. "Game Mode")
├── string Description
├── bool IsSelected
├── bool IsApplied (binds to UI-04 state display)
├── bool RequiresRestart
├── ICommand ApplyCommand
└── ICommand RevertCommand
```
