<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Service controller vs Registry | Services managed via ServiceController (runtime) + Registry Start=4 (persistence) — both must be consistent |
| User → System services | Service stop/start requires admin; non-elevated attempts blocked by manifest (Phase 4) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Tampering | Service name list | medium | mitigate | Service names are hardcoded in tweak classes (not user-controllable); catalog is trusted static file |
| T-04-02 | Tampering | Service Start registry value | medium | mitigate | Uses IRegistryProvider 2-arg OpenSubKey (Pitfall 1 prevention); RegistryView.Registry64 for HKLM |
| T-04-03 | Repudiation | Service stop without logging | high | mitigate | All service operations logged via ILogService with service name, operation type, and outcome |
| T-04-04 | Tampering | Service dependency chains | high | mitigate | ISystemServiceController exposes GetDependentServicesAsync; executor checks before stopping and warns/logs |
| T-04-SC | Spoofing | System.ServiceController API | medium | mitigate | System.ServiceController is part of .NET 10 runtime (no NuGet install needed) — verified |
</threat_model>
